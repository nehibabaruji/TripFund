# TripFund - Travel Planner

## Deskripsi

TripFund adalah sistem pengelolaan deposit pelanggan dan pembayaran uang muka vendor pada jasa travel planner.

## Fitur

- Dashboard transaksi
- Pencatatan DP pelanggan
- Pencatatan DP vendor
- Master data pelanggan
- Master data vendor
- Pencarian transaksi
- Filter transaksi
- Penghapusan transaksi
- Export laporan CSV
- Integrasi dengan Supabase

## Teknologi

- HTML
- CSS
- JavaScript
- Supabase
- PostgreSQL
